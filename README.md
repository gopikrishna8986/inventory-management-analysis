# Inventory Management Analysis

## Project Overview
This project analyzes inventory data to understand stock levels, sales, and ordering patterns across different product categories and regions.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard

## Key Analysis
- Total Units Sold by Category
- Inventory Level by Region
- Total Units Sold by Region
- Inventory Level by Category
- Units Ordered by Category

## Dashboard
An interactive Excel dashboard was created to summarize inventory performance.
